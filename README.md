# ML Mechanical Services Demo Website

A responsive static website demo for ML Mechanical Services.

## Pages
- Home: index.html
- Services hub: services.html
- Service areas hub: areas.html
- About: about.html

## GitHub Pages
The site is configured to publish from the `main` branch root. Once Pages finishes its first build, visit:

https://saddaturseam.github.io/Ml-Service/

The booking form opens the visitor's email app with an enquiry addressed to the contact email shown on the site. It does not use a server-side booking system.
